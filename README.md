A real-time facial recognition system built with Python and OpenCV. This project detects and recognizes faces using a webcam feed and can be used for security systems, attendance tracking, authentication systems, and computer vision projects. It automatically starts to record when a face is detected and will keep recording until the face is gone. The video is then stored locally on the storage drive.

Features
- Real-time face detection using webcam
- Face recognition with trained facial data
- Supports multiple cameras
- Fast and lightweight
- Built using OpenCV and Python
