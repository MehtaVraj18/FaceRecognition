A real-time facial recognition system built with Python and OpenCV. This project detects and recognizes faces using a webcam feed and can be used for security systems, attendance tracking, authentication systems, and computer vision projects. It automatically starts to record when a face is detected and will keep recording until the face is gone. The video is then stored locally on the storage drive. In the future, I want to upgrade the code so that it can save to a drive in the cloud allowing the videos to be accessed from anywhere. I also want to add a feature so it sends a notification to my phone when motion is detected.

Features
- Real-time face detection using webcam
- Face recognition with trained facial data
- Supports multiple cameras
- Fast and lightweight
- Built using OpenCV and Python
